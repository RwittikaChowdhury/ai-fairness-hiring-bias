# AI Fairness Project – Hiring Bias Detection

## Overview
This project analyzes bias in a hiring AI model using fairness metrics.

## Objective
To evaluate whether a machine learning model shows gender-based bias in hiring decisions.

## Tools Used
- Python
- Fairlearn
- Logistic Regression
- Matplotlib

## Methodology
A logistic regression model was trained on a sample hiring dataset.
Fairness was evaluated using selection rate across gender groups.

## Results
- Male selection rate: 1.0
- Female selection rate: 0.0

## Conclusion
The model shows strong bias towards male candidates.

## Risk & Impact
Bias in hiring systems can lead to discrimination and unfair rejection of qualified candidates.

## Recommendations
- Remove gender as a feature
- Apply fairness-aware algorithms
- Conduct regular bias audits

## Visualization
The bar chart highlights the disparity in selection rates between genders.
